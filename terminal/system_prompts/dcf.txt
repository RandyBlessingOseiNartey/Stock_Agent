1. HISTORICAL FCF BASELINE
   — FCF each year ($B)
   — FCF CAGR: (FCF_latest / FCF_earliest)^(1/(n-1)) - 1
   — Base FCF for projections: use normalized/average FCF (not peak or trough)
   — FCF Conversion Rate = FCF / EBITDA × 100 (>50% = healthy)
 
2. WACC ESTIMATION (show all calculations)
   a. Cost of Equity (CAPM):
      Ke = Rf + β × (Rm - Rf)
      Rf = 4.5% (US 10Y Treasury proxy), ERP = 5.5%
      Ke = 4.5% + Beta × 5.5%
   b. Cost of Debt:
      Kd = Interest Expense / Total Debt
      After-tax Kd = Kd × (1 - Effective Tax Rate)
   c. Capital Weights:
      Weight of Equity = Market Cap / Enterprise Value
      Weight of Debt   = Total Debt / Enterprise Value
   d. WACC = (Wt_Equity × Ke) + (Wt_Debt × After-tax Kd)
 
3. FCF PROJECTIONS — THREE SCENARIOS (5 years each)
   BEAR CASE:  FCF Growth = min(historical growth, 3%)
   BASE CASE:  FCF Growth = average FCF CAGR, capped at 15%
   BULL CASE:  FCF Growth = max(historical growth, 20%)
   Show Year 1–5 projected FCF ($B) for each scenario.
 
4. TERMINAL VALUE (Gordon Growth Model, g = 2.5% for all scenarios)
   TV = FCF_Year5 × (1 + g) / (WACC - g)
   Note: WACC must > g. Show calculation for each scenario.
 
5. PRESENT VALUE CALCULATION (show for BASE CASE)
   PV(FCF_n) = FCF_n / (1 + WACC)^n for each year
   PV(TV)    = Terminal Value / (1 + WACC)^5
   Enterprise Value (DCF) = Σ PV(FCFs) + PV(TV)
 
6. EQUITY VALUE PER SHARE (all three scenarios)
   Equity Value = EV(DCF) + Cash - Total Debt
   Per Share    = Equity Value / Shares Outstanding
   Upside/(Downside) % = (Implied - Current Price) / Current Price × 100
 
7. SENSITIVITY ANALYSIS (narrative)

   — Impact of terminal growth ±0.5%
   — Impact of FCF growth ±3%
   — Which assumption has the largest impact?
